Сайт создан с использованием HTML, CSS, JavaScript и Bootstrap 5. Полностью адаптивный дизайн для всех устройств.

## 🔧 Настройка GitHub Pages

Если вы получаете ошибку 404 при развертывании:

1. Перейдите в настройки репозитория на GitHub
2. В разделе "Pages" выберите:
   - **Source**: Deploy from a branch
   - **Branch**: main (или ваша основная ветка)
3. Нажмите "Save"
4. Подождите 2-3 минуты и обновите страницу

## 📱 Адаптивность
Сайт полностью адаптирован для:
- 📱 Мобильных устройств (320px+)
- 📟 Планшетов (768px+)
- 💻 Ноутбуков и десктопов (1024px+)

Используется Bootstrap 5 grid system для гибкой верстки.
